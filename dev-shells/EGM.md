# Dev Shells

## Overview

Defines the flake's default development shell for operating the infrastructure (deploys, secrets, caches). Loaded by `flake.nix` with the shared `importParams`.

## Interface

- `${system}.default`: `pkgs.mkShellNoCC` named `qois-infrastructure-shell` [default.nix:mkShellNoCC].
- Repository packages on PATH: `sops`, `sops-rekey`, `auto-deploy`, `diff-closures`, `qois-disk-unlock`, `grafana-mcp` from `self.packages.${system}` [default.nix:buildInputs].
- nixpkgs tools on PATH: `attic-client`, `deploy-rs`, `dix`, `jq`, `nix-diff`, `nix-fast-build`, `nixVersions.latest`, `nixd`, `nixos-anywhere`, `pssh`, `ssh-to-age`, `yq`, `kanidm_1_11` [default.nix:buildInputs].
- pre-commit packages from `git-hooks-nix` with a `treefmt` hook using `self.formatter.${system}`, `always_run = true` [default.nix:pre-commit-check].
- Environment: `LANG`/`LC_ALL=C.UTF-8`, `KANIDM_URL=https://id.qo.is` [default.nix:LANG, default.nix:shellHook].

## Invariants

- The shell hook must run inside a git checkout, because it calls `git rev-parse --show-toplevel` [default.nix:shellHook].
- `.sops.yaml` in the repo root is a build out-link of `.#sops-config`, not a hand-edited file [default.nix:shellHook].
- The pre-commit hook config is generated by `pre-commit-check.shellHook`, so entering the shell is required before the first commit [default.nix:pre-commit-check].

## Side Effects

- Runs `nix build --out-link $FLAKE_ROOT/.sops.yaml $FLAKE_ROOT#sops-config` on every shell entry [default.nix:shellHook].
- Appends each build input's `share` dir to `XDG_DATA_DIRS` for completions [default.nix:shellHook].
- Installs/generates the git pre-commit configuration [default.nix:pre-commit-check.shellHook].

## Verification

- Run: `nix develop`
- Run: `nix flake check`
