# Hardware Profiles

## Overview

Generic NixOS hardware modules imported by host configurations. Each imports `not-detected.nix` and sets initrd modules, KVM kernel module, CPU microcode and a default `nix.settings.max-jobs`. Legacy notes (serial console boot, BIOS keys) are in [README.md](./README.md).

## Interface

- `apu.nix`: PC Engines APU (AMD, `igb`), serial GRUB terminal, `boot.kernelParams = console=ttyS0,115200n8`, `kvm-amd`/`virtio`/`tun`, `hardware.cpu.amd.updateMicrocode`, `nix.settings.max-jobs` mkDefault 4, fwupd `DisabledPlugins = uefi_capsule, uefi_dbx` [apu.nix:boot, apu.nix:services.fwupd.daemonSettings].
- `apu1.nix`: older APU1 (`r8169`, `ohci_pci`), same serial console, AMD microcode, `max-jobs` mkDefault 2 [apu1.nix:boot, apu1.nix:nix.settings.max-jobs].
- `asrock-z790m.nix`: Asrock Z790M (Intel, `e1000e`), `kvm-intel`, Intel microcode, `powerManagement.cpuFreqGovernor = ondemand`, `max-jobs` mkDefault 8 [asrock-z790m.nix:boot, asrock-z790m.nix:powerManagement].
- `asrock.nix`: Asrock X570 (AMD, `nvme`, `igb`), `kvm-amd`, AMD microcode, `max-jobs` mkDefault 24 [asrock.nix:boot, asrock.nix:nix.settings.max-jobs].

## Invariants

- `apu.nix`, `apu1.nix`, `asrock-z790m.nix` carry a "generated by nixos-generate-config" header; `asrock.nix` does not [apu.nix:header].
- `nix.settings.max-jobs` is `mkDefault` everywhere and so overridable per host [apu.nix:max-jobs].
- Serial console settings are only in the APU profiles [apu.nix:boot.kernelParams, apu1.nix:boot.kernelParams].

## Side Effects

None beyond setting NixOS options (boot, microcode, fwupd plugin disabling in `apu.nix` only).
